# Changelog

## 0.4.1

- Added GitHub Releases `pluginURL` for Unraid update checks.
- No functional SecretGuard behavior changed.

## 0.4.0

First GitHub-ready public beta release, based on the tested v0.3.5 codebase.

- Publisher changed to `mr1beast`.
- Scan installed Docker containers only.
- Detect likely credentials without showing values.
- Managed `.env` secret storage.
- Encrypted Vault mode.
- Automatic Docker recreation after migration or rollback.
- Protection overview.
- Variable-level rollback without XML snapshot restoration.
- Matching User Utilities and Plugins icons.
- Aligned audit columns across container sections.
